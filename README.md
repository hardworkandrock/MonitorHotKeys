Monitor HotKeys
Управление мониторами с помощью горячих клавиш для Windows
Программа позволяет быстро настраивать конфигурацию нескольких мониторов через удобные горячие клавиши без необходимости открывать системные настройки.
🔥 Основные возможности
Загрузка/сохранение профилей конфигурации мониторов (Alt+F1-F3 / Alt+F10-F12)
Быстрое переключение основного монитора (Ctrl+Alt+F1-F3)
Мгновенное включение/отключение мониторов (Shift+Alt+F1-F3 / Shift+Alt+F10-F12)
Визуальная обратная связь с прогресс-баром при удержании клавиш
Поддержка нескольких языков (русский/английский) + возможность добавления новых
Работа из системного трея — минималистичный интерфейс без лишних окон

⚙️ Технические детали
Использует MultiMonitorTool от NirSoft для управления дисплеями
Все горячие клавиши работают глобально (даже в играх и полноэкранном режиме)
Защита от случайных срабатываний — команды выполняются только при удержании клавиш 1.5 секунды
Автоматическое обнаружение подключенных мониторов
🌐 Добавление новых языков
Программа поддерживает расширение списка языков через простые JSON-файлы:
Перейдите в папку Resources/Languages/
Создайте новый файл в формате {код_языка}.json (например, de.json для немецкого)
Скопируйте структуру из существующего файла (ru.json или en.json)
Переведите все значения на нужный язык
Добавьте новый язык в код (в метод ChangeLanguage и меню)
Подробная структура ключей описана в существующих файлах перевода.
📁 Генерируемые файлы
После первого запуска программа создает следующие файлы:
MonitorInfoList.json — кэш информации о подключенных мониторах (устройства, названия, статусы)
current_lang.txt — сохраняет выбранный пользователем язык между запусками
Profiles/ (папка) — содержит сохраненные профили конфигурации мониторов:
profile1.cfg, profile2.cfg, profile3.cfg — файлы профилей в формате MultiMonitorTool
📥 Установка
Скачайте последний релиз
Поместите MultiMonitorTool.exe в папку с программой
Запустите MonitorHotKeys.exe от имени администратора
Требования: Windows 10/11, .NET 6+
Идеально подходит для пользователей с несколькими мониторами, геймеров и тех, кто часто меняет конфигурацию дисплеев!
